# 欧翔 · 项目与科研成果

欧翔（Frank / OXnp666）的个人工程作品集，展示嵌入式、机器人、无人机与机器视觉项目。

## 网站内容

- 6 个精选项目和完整 GitHub 公开仓库目录
- 2 段真实源码，可切换及复制
- 作品影像和竞赛证书，可放大查看
- 项目手记、数学建模论文和其他成果入口
- 手机布局与 GitHub 仓库目录即时读取；读取失败时保留内置资料快照

## GitHub Pages

本仓库适用于个人主页仓库 `OXnp666/oxnp666.github.io`，预期网站地址为 `https://oxnp666.github.io/`。

这是静态网页，无需安装依赖或执行构建。启用 Pages 时，发布来源选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**。仓库根目录的 `.nojekyll` 可防止 Jekyll 处理。

## 文件

- `index.html`：页面内容
- `style.css`：页面样式
- `app.js`：交互和公开仓库同步
- `content.js`：项目、影像、证书及源码数据
- 根目录中的 6 个 JPG/PNG 文件：作品图片与奖状（与网页文件放在同一层）

资料来自 OXnp666 的公开仓库。个人、合作及资料整理项目分别标注；图片与证书提供原始资料链接。源码的权利和使用条件以各原始仓库为准，本仓库不额外授予原材料的许可。
